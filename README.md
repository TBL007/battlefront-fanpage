# Battlefront fanpage

A battlefront 2 fanpage

# setup

1. Clone repo
2. insert [Sql schema](/dokumentasjon/Database.sql) in db

3. setup all env variable

```env
BETTER_AUTH_SECRET=
BETTER_AUTH_URL=http://localhost:3000
DB_HOST = localhost
DB_USER =
DB_PASSWORD =
DB_DATABASE =

DISCORD_CLIENT_ID=
DISCORD_CLIENT_SECRET=

UPLOADTHING_TOKEN=
UPLOADTHING_SECRETKEY=
```

5. npm i
6. npm run dev

## Ide

- Battlefront 2 side
- har forum
- bruker innlogging muligens intregrere discord login?,
- About page med info om spilet
- galleri side med bruker publiserte bilder (litt som forumet)
- Bruker profiler med hva man har posta, dine likte poster/kommentarer,link til EA og discord konto hvis mulig ()
- news page / del av splash
- alle brukere har en side jedi/sith som reflekterer noe av designet til siden (enkelte knapp farger og tekst farger) dette vises også til andre brukere
